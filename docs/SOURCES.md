# Sources

## The organizer's material

A copy of this repository that carries these files lists them in
`ORGANIZER_MATERIAL.txt` (see NOTICE).

- `初賽規則_20260605.pdf`: the organizer's preliminary rules, header 2026/05/20, received 2026-06-05. Page 1 has the constraints and the interception definition; page 2 the scoring, tie order and reproducibility appendix.
- `第一屆軌道設計競賽_0510線上說明會簡報檔.pdf`: the slides of the organizer's online briefing of 2026-05-10. Page 8 has the workflow, input Script → edit B → run → Report → upload; page 10 the use of organizer computers and self-provided preliminary computation.
- The organizer's workshop template: a Hohmann-style two-burn example (F5 of `docs/SCORING_STRATEGY_AND_OPEN_QUESTIONS.md`). The tests use our `examples/two_burn_rendezvous.script`, of the same shape, in its place.
